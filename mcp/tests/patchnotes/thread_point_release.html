0.5.4 Patch Notes


  • This patch introduces a brand new Atlas Passive Tree for Runes of Aldur, expanded Expedition customisation, level-scaling Unique Items, a new currency item for Atziri’s Temple, and more.

Runes of Aldur Changes

  • Added an Expedition Atlas Passive Skill Tree. You can earn Atlas Passive Points for this by defeating each Boss in The Grand Expedition questline.

Bug Fixes

  • Made various improvements and bug fixes to the Trade Market UI when using a controller.
